# Braids by Helen v1.0.0

_Released October 13, 2026_

Braids by Helen is now an installable Progressive Web App with real time Web Push notifications. Helen can install the salon app directly to her mobile home screen and receive instant booking alerts the moment a client reserves an appointment.

## Highlights

- **Mobile Home Screen Installation**: Install Braids by Helen directly to your phone without downloading from an app store. Android and desktop visitors get a one tap install button, and iPhone visitors receive step by step visual guidance for Safari.
- **Instant Web Push Notifications**: Helen receives immediate background push alerts on mobile devices and desktop computers whenever a client submits an appointment reservation.
- **Fast Offline Experience**: Service worker caching loads the salon website, brand typography, and portfolio gallery instantly, even on slow or unreliable mobile connections.
- **Studio Notification Controls**: Helen can toggle device notifications on or off, assign device labels, and dispatch test alerts directly inside her studio management dashboard.
- **One Tap Appointment Deep Linking**: Tapping any incoming booking notification focuses your browser and takes you directly to the pending reservation for quick review and confirmation.

## Improvements

- **Dedicated Mobile App Metadata**: Full screen standalone display mode with salon theme colors and high resolution app icons for your phone home screen.
- **Seamless Local Demo Mode**: Push notification status and device registrations work in offline demo mode using local device storage when cloud database keys are absent.
- **Encrypted Web Push Standard**: Subscriptions use standard 256 bit VAPID application keys to ensure secure notification delivery without third party advertising trackers.

## How to get started

1. Open the Braids by Helen salon app in your mobile browser.
2. Tap the install banner to add the app to your home screen.
3. Open your studio dashboard, tap **Push Alerts**, and turn on notifications to start receiving real time appointment alerts.
