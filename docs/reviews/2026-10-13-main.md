## Minor

### 🟡 Environment VAPID key configuration, `src/services/pushNotificationService.js:7`
**Problem**: The push notification service uses a fallback demo VAPID key when `VITE_VAPID_PUBLIC_KEY` is undefined in the local environment.
**Why it matters**: For a live multi device deployment with background edge function dispatch, matching VAPID public and private keys must be saved in project secrets to avoid signature verification mismatches.
**Suggested fix**: Generate production VAPID keys via `web-push generate-vapid-keys` and declare `VITE_VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY` in `.env`.
