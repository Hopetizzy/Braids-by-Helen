# Lyna Hair Touch — Interactive Sales Demo & Scheduling Prototype

A mobile-first, high-polish salon booking prototype designed for **Lyna Hair Touch**. Demonstrating how direct online appointment self-scheduling eliminates WhatsApp back-and-forth messaging.

---

## 🌟 Key Features

- **Mobile-First Client Experience:** Effortlessly browse services, check upfront estimates, and view style variations on any device.
- **5-Step Frictionless Booking Engine:**
  1. Service & Style selection (Knotless Braids, Ghana Weaving, Passion Twists, Natural Hair, Threading, Kids Styling, Wigs)
  2. Interactive Date Picker with smart slot availability
  3. Morning, Afternoon, and Evening time slots
  4. Client contact details & hair/extension preferences
  5. Instant Confirmation Ticket with direct WhatsApp integration to Lyna Hair Touch (`+234 901 018 9746`) and Google Calendar action
- **Studio Schedule & Appointment Manager View:**
  - Real-time in-memory synchronization of new client bookings
  - KPI overview: Total Bookings, New Requests, Confirmed slots
  - One-click "Message on WhatsApp" for quick client confirmations
  - "Manage Services" and "Set Unavailability" planned feature controls
  - Responsive mobile dropdown filter for fast schedule navigation
- **Zero Generic AI Feel:** Bespoke luxury beauty palette, clean typography, authentic hairstyle visuals, and handcrafted Lucide iconography.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS (Custom luxury beauty theme)
- **Icons:** Lucide React
- **Animations:** Canvas-Confetti & Tailwind CSS animations

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/Hopetizzy/Lyna-Hair-Touch-Demo.git
cd Lyna-Hair-Touch-Demo
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Production Build
```bash
npm run build
```
